# Dixit Chaat House — Lucknow

A polished one-page website for Dixit Chaat House, a family-run chaat house in Lucknow founded in Chowk about 40 years ago and now run by the founder's grandson Gaurav Dixit, featuring its signature Basket Chaat prepared in pure desi ghee, menu highlights, opening hours, directions to the One World Vista branch on Amar Shaheed Path, and a WhatsApp enquiry form. The site is a single static HTML file (`index.html`) with inline CSS and a small inline script — no build step, no external images or dependencies — and can be deployed as-is to any static host.
