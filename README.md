# Dixit Chaat House — Lucknow

A polished one-page website for Dixit Chaat House, a family-run chaat house in Lucknow founded in Chowk in 1975 and now run by the founder's grandson Gaurav Dixit, featuring its signature Basket Chaat prepared in pure desi ghee, menu highlights, opening hours, directions to the One World Vista branch on Amar Shaheed Path, and a WhatsApp enquiry form. The site is a single static HTML file (index.html) with inline CSS and a small inline script — no build step, no external images or dependencies — and can be deployed as-is to any static host.

## Live site

https://dixit-chaat-house.vercel.app

- Second branch: One World Vista, Shalimar, Amar Shaheed Path, Lucknow 226010.

Menu highlights include Basket Chaat, Dahi Tikki and Matar Chaat. Prices are intentionally not listed on the site, so the shop can update them without a site change.
